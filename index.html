Over mij

Hallo! Ik ben een leerling uit de brugklas en ik volg het vak O&O (Onderzoek & Ontwerpen). Tijdens dit vak leer ik hoe ik onderzoek doe naar verschillende problemen en hoe ik daarvoor creatieve oplossingen kan ontwerpen.

Op deze website laat ik zien aan welke projecten ik heb gewerkt tijdens O&O. In de brugklas heb ik geleerd om onderzoek te doen, samen te werken, ontwerpen te maken en prototypes te bouwen. Deze projecten hebben mij geholpen om nieuwe vaardigheden te ontwikkelen en creatief na te denken over oplossingen.

Hieronder staan mijn vier O&O-projecten waarin ik heb gewerkt aan een knikkerbaan, een duurzame oplossing voor een festival, een nieuwe kantine voor Aqualectra en een oplossing tegen blauwalg.

Mijn Projecten

Project 1 - Knikkerbaan

De sloomste knikkerbaan maken.

Dit project ging over het ontwerpen van een slome knikkerbaan. We gebruikten karton, plakband en andere materialen. De knikkerbaan werkte goed, maar had op sommige plekken nog problemen.

Project 2 - Vakkanjers

Het ontwerpen van een duurzame oplossing voor een circulair festival.

Tijdens dit project hebben we een oplossing bedacht voor drinken. We maakten een prototype dat bekers schoonmaakt, zodat deze opnieuw gebruikt kunnen worden.

Project 3 - Aqualectra

Een nieuwe kantine ontwerpen voor Aqualectra.

Bij dit project moesten we een kantine of kantoortuin ontwerpen. Wij kozen voor de kantine. We hebben een model gebouwd, maar konden het niet helemaal afmaken.

Project 4 - Wattertoppers

Het ontwerpen van een idee tegen blauwalg.

Voor dit project hebben wij een oplossing bedacht tegen blauwalg. Ik onderzocht de oorzaken van blauwalg. We maakten een model waarbij een molentje golven creëert zodat je niet in het water hoeft te komen.
