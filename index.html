Mijn Projecten

Project 1 - Knikkerbaan

De sloomste knikkerbaan maken.

Dit project ging over het ontwerpen van een slome knikkerbaan. We gebruikte karton voor de knikkerbaan en plakband en andere materialen.

Project 2 - Vakkanjers

Het ontwerpen van een duurzame oplossing voor een circulair festival.

Tijdens dit project hebben we een oplossing bedacht voor drinken. We hadden een prototype gemaakt dat de bekers schoonmaakt, zodat je de beker opnieuw kunt gebruiken.

Project 3 - Aqualectra

Een nieuwe kantine ontwerpen voor Aqualectra.

Bij dit project moesten we een kantine of kantoortuin ontwerpen voor Aqualectra. Wij kozen de kantine, omdat dat ons leuker leek.

Project 4 - Wattertoppers

Het ontwerpen van een idee tegen blauwalg.

Voor dit project heb ik een oplossing bedacht tegen blauwalg. Ik onderzocht de oorzaken van blauwalg. We hadden een aparte bak gemaakt voor de dijkbouw en als je aan een molentje draait ontstaan er golven, waardoor je niet in het water hoeft te komen.
